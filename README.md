# Repositório de Estudos em C++

Este repositório é focado no estudo da linguagem **C++**, abordando desde os conceitos fundamentais da programação até recursos mais avançados da linguagem.

O principal material utilizado é o livro:

* **C++23 Para Windows** — *Augusto Manzano*

Além dele, também são utilizados conteúdos do livro:

* **Algoritmos – Lógica de Programação** — *Augusto Manzano*

---

# Objetivo

O objetivo deste repositório é registrar a evolução nos estudos de:

* Lógica de programação
* Estruturas fundamentais da linguagem C++
* Boas práticas de desenvolvimento
* Exercícios e exemplos práticos
* Implementações utilizando recursos modernos da linguagem

---

# Conteúdos Estudados

O livro **C++23 Para Windows** apresenta o aprendizado da linguagem de forma didática e prática, iniciando pelos conceitos básicos e evoluindo gradualmente para tópicos mais avançados.

Entre os assuntos abordados estão:

* Programação linear
* Estruturas de decisão
* Estruturas de repetição
* Vetores e matrizes
* Ponteiros
* Structs
* Classes e orientação a objetos
* Manipulação de arquivos
* Funções
* Modularização
* Recursos modernos do C++
* Práticas utilizadas no mercado

O material também apresenta exemplos de boas e más práticas de programação, contribuindo para o desenvolvimento de uma visão mais crítica sobre código e arquitetura.
